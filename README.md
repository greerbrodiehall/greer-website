# greerbrodiehall.com

- `index.html` is the design. Don't edit it for wording changes.
- `content.json` holds every word, number, price, photo and video on the site.
- `media/` holds the photos and videos.
- `.pages.yml` sets up the Pages CMS editor (app.pagescms.org), so content.json can be edited through a form.

Video rows: keep each "more videos" list to 4 or 8 so rows stay full.
